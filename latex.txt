\section{System Overview}
% ══════════════════════════════════════════════════════════════════════════

\begin{bluebox}
\textbf{Core Thesis Claim:} We present the first agentic multimodal AI system for football officiating that produces five simultaneous outputs: a foul decision, a severity prediction, a spatial attention heatmap, a temporal attention timeline, and a structured natural language report grounded in the Laws of the Game. No prior sports XAI system produces all five.
\end{bluebox}

\vspace{8pt}

The system is built as a \textbf{LangGraph directed graph} where each node is a Python function reading from and writing to a shared \texttt{RefereeState} dictionary. Three conditional loops make it genuinely agentic — the system can re-examine evidence, regenerate explanations, and verify faithfulness before producing its final output.

\vspace{8pt}

\begin{center}
\begin{tabular}{lll}
\toprule
\textbf{Property} & \textbf{This System} & \textbf{X-VARS (Baseline)} \\
\midrule
Visual grounding        & Frame-level heatmap   & None \\
Temporal grounding      & Frame attention scores & None \\
Text-video fusion       & Cross-attention        & Average pooling \\
Rule grounding          & FAISS Laws of the Game & None \\
Historical cases        & FAISS case database    & None \\
Multi-agent explanation & 4 Workers + Instructor & Single LLM \\
Faithfulness check      & FaithScore + loop      & None \\
Bias resistance         & Contrastive training   & None \\
Agentic loops           & 3 conditional loops    & 0 \\
\bottomrule
\end{tabular}
\end{center}

\section{Node-by-Node Specification}
% ══════════════════════════════════════════════════════════════════════════

Each node is explained with its function, inputs, outputs, and the technical operation it performs.

\vspace{10pt}

% ── NODE 1 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=inputbg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N1 — Frame Analysis Node}}
\hfill\textcolor{lightblue}{\small Input Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Load raw frames from disk and prepare them for CLIP.

\textbf{Reads:} \texttt{clip\_path}

\textbf{Writes:} \texttt{frames (64, 224, 224, 3)}

\textbf{Operation:} Loads the pre-extracted \texttt{.npy} file. Converts \texttt{uint8} to float. Applies CLIP preprocessing: resize to 224×224, normalize to $[-1, 1]$ using ImageNet mean and std. Returns 64 frames ready for the visual encoder.

\textbf{Why 64 frames:} A 5-second clip at 25fps contains 125 frames. Sampling every 2nd frame gives 64 — sufficient to capture the contact moment (which lasts $\approx 5$ frames) while keeping the attention matrix size at $64 \times 64 = 4096$ pairs, well within the 12GB VRAM budget.
\end{graybox}

\vspace{6pt}

% ── NODE 2 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=nodebg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N2 — CLIP Vision Encoder Node}}
\hfill\textcolor{lightblue}{\small Vision Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Extract both CLS tokens and spatial patch tokens from all 64 frames simultaneously.

\textbf{Reads:} \texttt{frames}

\textbf{Writes:} \texttt{cls\_tokens (64, 1024)}, \texttt{spatial\_tokens (64, 256, 1024)}

\textbf{Operation:} Runs all 64 frames through CLIP ViT-L/14 in one batched forward pass. Instead of using only the pooled CLS token as standard CLIP does, this node retains the full $256$ spatial patch tokens per frame — each representing a $14\times14$ pixel region in the 16×16 patch grid. This is the core innovation: $256 \times 1024 = 262{,}144$ spatial features per frame versus $1{,}024$ with standard CLIP.

\textbf{Why this matters:} X-VARS discards spatial tokens through average pooling before feeding to the LLM. Retaining them enables the heatmap generation in N6.
\end{graybox}

\vspace{6pt}

% ── NODE 3 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=nodebg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N3 — CLIP Text Encoder Node}}
\hfill\textcolor{lightblue}{\small Text Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Generate semantic text embeddings from label-derived text descriptions.

\textbf{Reads:} \texttt{clip\_path} (to look up annotation labels)

\textbf{Writes:} \texttt{text\_features (1, 1024)}

\textbf{Operation:} Converts annotation labels to natural language using the template:\\
\textit{``A [action\_class] challenge. [Foul/No foul]. [Card decision].''}\\
Encodes this text through CLIP's text transformer to produce a 1024-dim semantic embedding. At inference, when labels are unknown, a neutral prompt is used: \textit{``A football challenge between two players.''}

\textbf{Novel aspect:} No prior sports XAI paper uses text as a second modality alongside video features during classification. This bridges the gap between what is seen and what is semantically expected.
\end{graybox}

\vspace{6pt}

% ── NODE 4 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=fusionbg, linecolor=purple!60, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N4 — Cross-Attention Fusion Node}}
\hfill\textcolor{lightpurple}{\small Fusion Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Align video features with text semantics using cross-attention.

\textbf{Reads:} \texttt{cls\_tokens}, \texttt{text\_features}

\textbf{Writes:} \texttt{video\_vector (1, 1024)}

\textbf{Operation:} The cross-attention mechanism allows video frame tokens to attend to the text feature:
\[
\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]
where $Q$ = video features (queries), $K, V$ = text features (keys, values). This forces video features representing ``tackling'' to align with the text token for ``tackling''. The output is a text-conditioned video representation that is significantly more discriminative than video features alone.

\textbf{Why this improves classification:} Vanilla CLIP features for foul and no-foul clips are nearly identical. Adding text conditioning gives the model a semantic anchor that separates the feature space.
\end{graybox}

\vspace{6pt}

% ── NODE 5 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=midblue, linecolor=accentblue!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N5 — Classification Node}}
\hfill\textcolor{lightblue}{\small Decision Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Predict foul type and severity from the fused video-text representation.

\textbf{Reads:} \texttt{video\_vector}

\textbf{Writes:} \texttt{foul\_logits (1,2)}, \texttt{sev\_logits (1,4)}, \texttt{foul\_pred}, \texttt{sev\_pred}, \texttt{foul\_confidence}

\textbf{Operation:} Two lightweight MLP classifier heads (C\_foul and C\_sev) trained with Focal Loss to handle class imbalance (86\% fouls vs 14\% no-fouls). Focal Loss downweights easy examples:
\[
\mathcal{L}_\text{focal} = -(1 - p_t)^\gamma \log(p_t), \quad \gamma = 2.0
\]
Confidence score is $\max(\text{softmax}(\text{logits}))$.
\end{graybox}

\vspace{6pt}

% ── LOOP 1 ─────────────────────────────────────────────────────────────
\begin{redbox}
\textbf{Agentic Loop 1 — Confidence Check}\\
If \texttt{foul\_confidence} $<$ 0.7 AND \texttt{conf\_retry} $<$ 3: go back to N4 with adjusted text prompt. If confident OR max retries reached: proceed to N6. This forces the agent to seek additional evidence before committing to a low-confidence decision.
\end{redbox}

\vspace{6pt}

% ── NODE 6 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=teal, linecolor=accentgreen!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N6 — Spatio-Temporal Heatmap Node}}
\hfill\textcolor{lightteal}{\small Visual XAI Layer — Core Contribution}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Generate both spatial and temporal attention heatmaps. This is the primary thesis contribution — no prior system produces both.

\textbf{Reads:} \texttt{spatial\_tokens}, \texttt{cls\_tokens}, \texttt{frames}

\textbf{Writes:} \texttt{spatial\_heatmaps (64, 224, 224)}, \texttt{temporal\_attn (64,)}, \texttt{hot\_frames}, \texttt{hot\_regions}

\textbf{Spatial heatmap (WHERE):}
\begin{enumerate}[leftmargin=1.5em, itemsep=2pt]
  \item Compute L2 norm of each spatial token: scores $\in \mathbb{R}^{64 \times 256}$
  \item Normalize to $[0,1]$ per frame
  \item Reshape to $16 \times 16$ patch grid
  \item Upsample to $224 \times 224$ via bicubic interpolation
  \item Apply JET colormap: blue = low attention, red = high
  \item Blend with original frame at $\alpha = 0.5$
\end{enumerate}

\textbf{Temporal heatmap (WHEN):}
\begin{enumerate}[leftmargin=1.5em, itemsep=2pt]
  \item CLS tokens pass through Temporal Transformer (2 layers, 8 heads)
  \item CLS token $\in \mathbb{R}^{1024}$ attends to all 64 frame tokens
  \item Attention weights give temporal importance per frame: $\alpha \in \mathbb{R}^{64}$
  \item Peak frames ($\alpha > 0.8 \times \max(\alpha)$) identified as \texttt{hot\_frames}
\end{enumerate}

\textbf{Output:} For each hot frame $f \in$ \texttt{hot\_frames}, a body region label (head, torso, legs, feet) is extracted from the peak spatial attention patch. This feeds directly into Workers N8a--N8d.
\end{graybox}

\vspace{6pt}

% ── NODE 7 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=orange!80!black, linecolor=orange!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N7a/b — Knowledge Retrieval Nodes}}
\hfill\textcolor{lightorange}{\small Retrieval Layer}
\end{mdframed}

\begin{graybox}
\textbf{N7a — Laws of the Game Retrieval}

\textbf{Function:} Find the specific FIFA Law clause that applies to the detected foul.

\textbf{Reads:} \texttt{foul\_pred}, \texttt{hot\_regions}

\textbf{Writes:} \texttt{retrieved\_rules} (top-3 Law clauses)

\textbf{Operation:} Query = foul type + body region (e.g. ``careless tackling leg contact''). FAISS cosine similarity search over embeddings of all FIFA Laws of the Game clauses. Embeddings created using CLIP text encoder at build time. Returns top-3 most semantically relevant clauses.

\vspace{6pt}

\textbf{N7b — Historical Cases Retrieval}

\textbf{Function:} Find similar past referee decisions from the training dataset.

\textbf{Reads:} \texttt{foul\_pred}, \texttt{sev\_pred}

\textbf{Writes:} \texttt{retrieved\_cases} (top-3 similar cases)

\textbf{Operation:} Query = foul type + severity label. FAISS search over SoccerNet-XFoul annotations embedded as text. Returns 3 historical cases with their referee explanations — providing few-shot examples for the Worker LLMs.
\end{graybox}

\vspace{6pt}

% ── NODES 8a-8d ────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=workerbg, linecolor=accentgreen!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N8a--N8d — Four Worker Agent Nodes}}
\hfill\textcolor{lightgreen}{\small Generation Layer}
\end{mdframed}

\begin{graybox}
Each Worker is a small LLM (Phi-3-mini, 3.8B) with a focused task. They run sequentially, each receiving the previous worker's output as context.

\vspace{6pt}
\begin{tabular}{llp{8cm}}
\toprule
\textbf{Node} & \textbf{Name} & \textbf{Task and Output} \\
\midrule
N8a & Visual Explanation
  & Receives hot frames, hot regions, foul prediction. Generates 2--3 sentences describing the physical contact: \textit{``The defender made careless contact with the attacker's leg at frame 32, in the lower body region.''} \\
\midrule
N8b & Rule Citation
  & Receives N8a output + retrieved law clauses. Cites the specific Law number and clause: \textit{``Under Law 12, Section 3, a player who challenges an opponent carelessly must be cautioned.''} \\
\midrule
N8c & Severity Reasoning
  & Receives N8b output + severity prediction + historical cases. Justifies the card decision with reference to similar past cases: \textit{``Given the moderate intensity (attention score 0.72) and leg contact, consistent with 3 historical yellow card decisions.''} \\
\midrule
N8d & Temporal Analysis
  & Receives temporal attention weights + hot frame indices. Describes when in the clip the decisive moment occurred: \textit{``Peak attention at frames 30--35 (seconds 1.9--2.2 of clip), confirming the contact moment is precisely locatable.''} \\
\bottomrule
\end{tabular}
\end{graybox}

\vspace{6pt}

% ── LOOP 2 ─────────────────────────────────────────────────────────────
\begin{redbox}
\textbf{Agentic Loop 2 — Faithfulness Check (FaithScore)}\\
Computes FaithScore: extracts body part mentions from N8a text, maps to spatial patch regions, checks if heatmap attention is high in those regions. If FaithScore $< 0.7$ AND \texttt{faith\_retry} $< 2$: loop back to N8a with constraint \textit{``Your explanation must reference the [body\_region] region shown in the heatmap.''} If faithful OR max retries: proceed to N12.
\end{redbox}

\vspace{6pt}

% ── NODE 12 ────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=outputbg, linecolor=orange!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N12 — Instructor LLM Node (Report Synthesis)}}
\hfill\textcolor{lightorange}{\small Instructor Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Act as the orchestrating Instructor. Synthesize all four Worker outputs into one coherent, structured referee decision report.

\textbf{Reads:} All Worker outputs, predictions, hot regions, FaithScore, retrieved rules

\textbf{Writes:} \texttt{final\_report}

\textbf{Operation:} The Instructor (DeepSeek-V3 via API, or GPT-4o) receives a structured prompt containing all Worker summaries and produces the final report. It cross-checks consistency between Workers — for example, if N8b cites Law 12 but N8c recommends no card, the Instructor resolves the contradiction.

\textbf{Inspired by:} Gao et al. (2025) Instructor-Worker architecture for GIS data analysis. Extended here to multimodal video understanding with visual grounding.
\end{graybox}

\vspace{6pt}

% ── NODE 13 ────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=accentred!80, linecolor=accentred!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N13 — Final Output Node}}
\hfill\textcolor{lightred}{\small Output Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Package all outputs into the final structured referee report and compute evaluation metrics.

\textbf{Reads:} \texttt{final\_report}, \texttt{faith\_score}, predictions, heatmaps

\textbf{Writes:} \texttt{bert\_score}, formatted output package

\textbf{Output format:}

\section{The Three Agentic Loops}
% ══════════════════════════════════════════════════════════════════════════

\begin{center}
\begin{tikzpicture}[

\node[loopbox, fill=lightteal, draw=teal, below=of loop2] (loop3) {

  ++(0,0.5) -- ++(-0.4,0);

\end{tikzpicture}
\end{center}

\vspace{8pt}

The three loops make this a genuinely agentic system. A non-agentic system processes each node exactly once and stops. This system can iterate — re-examining evidence, regenerating text, and resolving contradictions — before committing to a final output. This is directly analogous to how a human VAR referee reviews footage multiple times before a decision.

\section{System Overview}
% ══════════════════════════════════════════════════════════════════════════

\begin{bluebox}
\textbf{Core Thesis Claim:} We present the first agentic multimodal AI system for football officiating that produces five simultaneous outputs: a foul decision, a severity prediction, a spatial attention heatmap, a temporal attention timeline, and a structured natural language report grounded in the Laws of the Game. No prior sports XAI system produces all five.
\end{bluebox}

\vspace{8pt}

The system is built as a \textbf{LangGraph directed graph} where each node is a Python function reading from and writing to a shared \texttt{RefereeState} dictionary. Three conditional loops make it genuinely agentic — the system can re-examine evidence, regenerate explanations, and verify faithfulness before producing its final output.

\vspace{8pt}

\begin{center}
\begin{tabular}{lll}
\toprule
\textbf{Property} & \textbf{This System} & \textbf{X-VARS (Baseline)} \\
\midrule
Visual grounding        & Frame-level heatmap   & None \\
Temporal grounding      & Frame attention scores & None \\
Text-video fusion       & Cross-attention        & Average pooling \\
Rule grounding          & FAISS Laws of the Game & None \\
Historical cases        & FAISS case database    & None \\
Multi-agent explanation & 4 Workers + Instructor & Single LLM \\
Faithfulness check      & FaithScore + loop      & None \\
Bias resistance         & Focal loss weighting   & None \\
Agentic loops           & 3 conditional loops    & 0 \\
\bottomrule
\end{tabular}
\end{center}

\newpage
\section{Node-by-Node Specification}
% ══════════════════════════════════════════════════════════════════════════

Each node is explained with its function, inputs, outputs, and the technical operation it performs.

\vspace{10pt}

% ── NODE 1 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=inputbg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N1 — Frame Analysis Node}}
\hfill\textcolor{lightblue}{\small Input Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Load raw frames from disk and prepare them for SigLIP / CLIP.

\textbf{Reads:} \texttt{clip\_path}

\textbf{Writes:} \texttt{frames (16, 384, 384, 3)}

\textbf{Operation:} Loads the pre-extracted features or raw frame sequences. Converts \texttt{uint8} to float. Applies visual encoder preprocessing: resize to 384×384, normalize to $[-1, 1]$ using standard ImageNet mean and std. Returns 16 sampled HD frames ready for the visual encoder.
\end{graybox}

\vspace{6pt}

% ── NODE 2 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=nodebg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N2 — Vision Encoder Node (SigLIP-SO400M)}}
\hfill\textcolor{lightblue}{\small Vision Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Extract both CLS tokens and spatial patch tokens from all frames simultaneously.

\textbf{Reads:} \texttt{frames}

\textbf{Writes:} \texttt{cls\_tokens (16, 1152)}, \texttt{spatial\_tokens (16, 729, 1152)}

\textbf{Operation:} Runs all 16 frames through SigLIP-SO400M in one batched forward pass. Retains spatial patch tokens per frame representing fine-grained spatial patch grids.
\end{graybox}

\vspace{6pt}

% ── NODE 3 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=nodebg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N3 — Text Encoder Node}}
\hfill\textcolor{lightblue}{\small Text Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Generate semantic text embeddings from label-derived text descriptions.

\textbf{Reads:} \texttt{clip\_path} (to look up annotation labels)

\textbf{Writes:} \texttt{text\_features (1, 1152)}

\textbf{Operation:} Converts annotation labels to natural language using the template:\\
\textit{``A [action\_class] challenge. [Foul/No foul]. [Card decision].''}\\
Encodes this text through the text transformer to produce a 1152-dim semantic embedding.
\end{graybox}

\vspace{6pt}

% ── NODE 4 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=fusionbg, linecolor=purple!60, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N4 — Cross-Attention Fusion Node}}
\hfill\textcolor{lightpurple}{\small Fusion Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Align video features with text semantics using cross-attention.

\textbf{Reads:} \texttt{cls\_tokens}, \texttt{text\_features}

\textbf{Writes:} \texttt{video\_vector (1, 1152)}

\textbf{Operation:} The cross-attention mechanism allows video frame tokens to attend to text features:
\[
\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]
where $Q$ = video features (queries), $K, V$ = text features (keys, values).
\end{graybox}

\vspace{6pt}

% ── NODE 5 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=midblue, linecolor=accentblue!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N5 — Classification Node}}
\hfill\textcolor{lightblue}{\small Decision Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Predict foul type and severity from the fused representation.

\textbf{Reads:} \texttt{video\_vector}

\textbf{Writes:} \texttt{foul\_logits (1,2)}, \texttt{sev\_logits (1,4)}, \texttt{foul\_pred}, \texttt{sev\_pred}, \texttt{foul\_confidence}

\textbf{Operation:} Two lightweight MLP classifier heads (C\_foul and C\_sev) trained with Focal Loss to handle class imbalance:
\[
\mathcal{L}_\text{focal} = -(1 - p_t)^\gamma \log(p_t), \quad \gamma = 2.0
\]
\end{graybox}

\vspace{6pt}

% ── LOOP 1 ─────────────────────────────────────────────────────────────
\begin{redbox}
\textbf{Agentic Loop 1 — Confidence Check}\\
If \texttt{foul\_confidence} $<$ 0.7 AND \texttt{conf\_retry} $<$ 3: go back to N4 with adjusted text prompt. If confident OR max retries reached: proceed to N6.
\end{redbox}

\vspace{6pt>

% ── NODE 6 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=teal, linecolor=accentgreen!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N6 — Spatio-Temporal Heatmap Node}}
\hfill\textcolor{lightteal}{\small Visual XAI Layer — Core Contribution}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Generate spatial and temporal attention heatmaps for visual explainability.

\textbf{Reads:} \texttt{spatial\_tokens}, \texttt{cls\_tokens}, \texttt{frames}

\textbf{Writes:} \texttt{spatial\_heatmaps}, \texttt{temporal\_attn}, \texttt{hot\_frames}, \texttt{hot\_regions}
\end{graybox}

\vspace{6pt}

% ── NODE 7 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=orange!80!black, linecolor=orange!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N7a/b — Knowledge Retrieval Nodes}}
\hfill\textcolor{lightorange}{\small Retrieval Layer}
\end{mdframed}

\begin{graybox}
\textbf{N7a — Laws of the Game Retrieval:} FAISS cosine similarity search over embeddings of FIFA Laws of the Game clauses.

\textbf{N7b — Historical Cases Retrieval:} FAISS search over historical SoccerNet-XFoul annotations.
\end{graybox}

\vspace{6pt}

% ── NODES 8a-8d ────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=workerbg, linecolor=accentgreen!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N8a--N8d — Four Worker Agent Nodes (Phi-3-mini)}}
\hfill\textcolor{lightgreen}{\small Generation Layer}
\end{mdframed}

\begin{graybox}
Each Worker is a fine-tuned or prompt-instructed LLM (Phi-3-mini, 3.8B) with a focused task:
\begin{itemize}[leftmargin=1.5em]
  \item \textbf{N8a Visual Explanation:} Explains physical contact based on visual features.
  \item \textbf{N8b Rule Citation:} Cites specific FIFA Law clauses.
  \item \textbf{N8c Severity Reasoning:} Justifies yellow/red card decisions.
  \item \textbf{N8d Temporal Analysis:} Identifies the exact moment of contact.
\end{itemize}
\end{graybox}

\vspace{6pt}

% ── LOOP 2 ─────────────────────────────────────────────────────────────
\begin{redbox}
\textbf{Agentic Loop 2 — Faithfulness Check (FaithScore)}\\
Computes FaithScore: checks if textual claims align with visual heatmap regions. If FaithScore $<$ 0.7 AND \texttt{faith\_retry} $<$ 2: loop back to N8a.
\end{redbox}

\vspace{6pt}

% ── NODE 12 ────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=outputbg, linecolor=orange!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N12 — Instructor LLM Node (Report Synthesis)}}
\hfill\textcolor{lightorange}{\small Instructor Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Synthesize all Worker outputs into one coherent, structured referee decision report.
\end{graybox}

\vspace{6pt}

% ── NODE 13 ────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=accentred!80, linecolor=accentred!50, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N13 — Final Output Node}}
\hfill\textcolor{lightred}{\small Output Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Package all outputs into the final structured referee report and compute evaluation metrics (BERTScore, FaithScore).
\end{graybox}

\section{The Three Agentic Loops}

\begin{center}
\begin{tikzpicture}[
  node distance=0.8cm,
  loopbox/.style={rectangle, rounded corners=8pt, draw, line width=1.2pt,
    minimum width=12cm, minimum height=1.8cm, align=left,

\node[loopbox, fill=lightred, draw=accentred] (loop1) {
  \textbf{\textcolor{accentred}{Loop 1 — Confidence Re-examination}}\\
  \textcolor{darkgray}{\small Trigger: foul confidence $<$ 0.7 | Max retries: 3 | Back to: N4 (fusion)}\\
  \textcolor{darkgray}{\small Effect: Adjusts text prompt to focus on ambiguous contact region and re-fuses}
};

\node[loopbox, fill=lightpurple, draw=purple, below=of loop1] (loop2) {

\node[loopbox, fill=lightteal, draw=teal, below=of loop2] (loop3) {

  \textcolor{darkgray}{\small Effect: Instructor detects Law/severity contradiction, Worker 2 re-cites rule}
};

  (loop1.east) -- ++(0.4,0) -- ++(0,0.4) --
  node[right, font=\small, color=accentred] {if still uncertain}
  ++(0,0.5) -- ++(-0.4,0);

\end{tikzpicture}

\begin{bluebox}

\section{Node-by-Node Specification}
% ══════════════════════════════════════════════════════════════════════════

Each node is explained with its function, inputs, outputs, and the technical operation it performs.

\vspace{10pt}

% ── NODE 1 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=inputbg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N1 — Frame Analysis Node}}
\hfill\textcolor{lightblue}{\small Input Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Load raw frames from disk and prepare them for SigLIP / CLIP.

\textbf{Reads:} \texttt{clip\_path}

\textbf{Writes:} \texttt{frames (16, 384, 384, 3)}

\textbf{Operation:} Loads the pre-extracted features or raw frame sequences. Converts \texttt{uint8} to float. Applies visual encoder preprocessing: resize to 384×384, normalize to $[-1, 1]$ using standard ImageNet mean and std. Returns 16 sampled HD frames ready for the visual encoder.
\end{graybox}

\vspace{6pt}

% ── NODE 2 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=nodebg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N2 — Vision Encoder Node (SigLIP-SO400M)}}
\hfill\textcolor{lightblue}{\small Vision Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Extract both CLS tokens and spatial patch tokens from all frames simultaneously.

\textbf{Reads:} \texttt{frames}

\textbf{Writes:} \texttt{cls\_tokens (16, 1152)}, \texttt{spatial\_tokens (16, 729, 1152)}

\textbf{Operation:} Runs all 16 frames through SigLIP-SO400M in one batched forward pass. Retains spatial patch tokens per frame representing fine-grained spatial patch grids.
\end{graybox}

\vspace{6pt}

% ── NODE 3 ─────────────────────────────────────────────────────────────
\begin{mdframed}[backgroundcolor=nodebg, linecolor=accentblue, linewidth=1.5pt,
  roundcorner=5pt, innertopmargin=10pt, innerbottommargin=10pt,
  innerleftmargin=12pt, innerrightmargin=12pt]
\textcolor{white}{\textbf{N3 — Text Encoder Node}}
\hfill\textcolor{lightblue}{\small Text Layer}
\end{mdframed}

\begin{graybox}
\textbf{Function:} Generate semantic text embeddings from label-derived text descriptions.

\textbf{Reads:} \texttt{clip\_path} (to look up annotation labels)

\textbf{Writes:} \texttt{text\_features (1, 1152)}

\textbf{Operation:} Converts annotation labels to natural language using the template:\\
\textit{``A [action\_class] challenge. [Foul/No foul]. [Card decision].''}\\
